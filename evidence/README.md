# evidence/ —— 不能重跑的现场数据摘要

放这里的东西只有一个判断标准：**当时那一刻的读数，仓库里别处再也拿不到**。
能重算的一律不进来占地方（下面标了"可重跑"的那些，是为了说明它们**不需要**被相信）。

每个文件都带 `_what` / `_command` / `_doc`：命令能抄回去跑，章节能回去看判读；
数字不是我手打的，是从板外的原始回读文件重新算出来的
（算的脚本在板外 `collect_evidence.py`，因为它读的原始文件不在仓库里）。

## 三条读它的人必须知道的话

1. **12/12 只证明铺铜算法与源优先级一致**，不证明岛铜间距符合源里的 8 mil 规则——
   那一步到现在还没做（`docs/SOP-eda-import-2.6.1.md` 第 7 节）。
2. **`BOOST_LOOP` 现在稳定读到 10 块**，§C-15 当时记的是 11；追这一格要做写操作，本轮没做。
3. **EDA 那两个数字不能凭这份 JSON 复现**——它依赖一台开着 4.1.60、且已经按 SOP 手工导入过
   两次的宿主。新板直接导入是 10/12，那是已知行为，不是这里的数据错了。
