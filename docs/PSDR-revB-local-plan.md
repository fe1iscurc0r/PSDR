## 1. 硬件改动（都落在"铜/丝印/制造参数"上，不是换值）

### H-1 `VDDBG` 供电（对应缺陷 D-02，最高优先）

* 现状：`VDDBG`(U287.28) 只连 `C292.1`，没有电源（网表 `$$$15137`）。
* **rev-B 改法**：从 `LPF_5V` 最近的节点拉一段铜到 `C292.1`。
  实测坐标（贴装表，mm）：`C292` (34.29, 9.91)；`LPF_5V` 上最近的电容是 **`C291` (37.08, 13.21)，距离 4.3 mm**；
  其余 `C290` 5.4 mm、`C295` 6.4 mm。
* **台架等价做法**（不改板）：30 AWG 飞线 `C292.1` ↔ `C291` 的 `LPF_5V` 端；飞完量 pin 28 对地 ≈5 V。
* 验收：pin 28 = 4.9–5.1 V；HMC1023 的 `VDDBG` 电流正常（手册未给上限，量电压即可）。

### H-2 线距成簇修复（对应 D-14）

52 条 `clearance` 实测 **0.1174–0.1986 mm**（源规则 0.2032 mm）。按 `dist/revB/clearance_clusters.csv` 成簇处理：

| 簇 | 条数 | 处理 |
|---|---|---|
| U86 周围（MAX4525） | 6 | 挪 B.Cu 的 GND 走线，让出 ≥0.2 mm |
| U241 周围（Si5338） | 5 | 同上（GND 走线贴焊盘） |
| C118 / C119 / GPSR 周围 | 各 3 | 局部改线 |
| U253 / U287 / C256 / C257 / C179 / R117 / REF | 各 2 | 局部改线 |

* **目标值**：源规则 **≥0.2032 mm**（8 mil）；若只为过厂规，最低 **≥0.15 mm**（约 6 mil），但**建议按源规则改**，避免下次再被 DRC 抓。
* 验收：改后 `clearance` 违规 = 0（KiCad DRC 同为规则 0.2 mm 时）；圈外 262 件坐标/网络不变。

### H-3 板厚与叠层口径（对应 D-16）

* 源叠层算得 **0.899 mm**；下单按 **1.0 mm**（常见档）或向厂确认 0.9 mm。
* 叠层：4 层 / FR4 εr 4.3 / 1 oz / 介质 3×0.254 mm；表面处理**沉金**。
* 验收：下单页参数与 §6 的表格逐项一致；DFM 预检用**原始 Gerber 包**。

### H-4 丝印让位（对应 D-17）

把压在焊盘/过孔上的位号（199 条 `silk_over_copper` 的典型位置）挪开 ≥0.2 mm；**只动丝印层**，不动铜。
验收：丝印 DRC 的 `silk_over_copper` 从 199 降到 ≤ 个位数（允许保留连接器处无法避免的少数）。

### H-5 `U30` pin 6 引出（可选，服务于滤波扩展）

`U30.6`（ANT2）无网络。rev-B 可把它引到一个测试点/焊盘，供将来外接滤波器切换用。
验收：新增一个网络与一个测试点；不影响其它网络。

## 6. "不算解决"的清单（按你的口径，单列不计入）

* **换 R113 得到 3.3 V**（D-11）：只是换值，按你的口径不算"解决"；但它可能是唯一手段——若实测轨 <2.9 V，
  这是必须做的"最小必要换值"，我会单独标注，不混进本表。
* **11 个值冲突**（D-12）：多数票已定，最终仍以实测为准；换值本身不算解决。
* **CB3Q/CBTLV**（D-13）：若实物是 CB3Q，网表改名即可（不改硬件），算文档级修正，不算"改动"。
* **缺料替代**（U304/DPDT）：明确不在本规划内。
