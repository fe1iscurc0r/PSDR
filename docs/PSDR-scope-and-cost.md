# PSDR 的最初需求、成本结构与"该砍什么"（fork-only）

日期：2026-11-02。用户要求先明确"最初的需求"，再谈降本与去冗余；并明确一个原则：
**不为可扩展性设计**（可证伪性优先——做不出来的扩展不算功能）。本文只做梳理与建议，不改设计。

## 1. 最初的需求（作者自己在 `README.md` 里写的，不是我们猜的）

> PortableSDR —— 一台**独立（standalone）的 HF 软件定义收发信机**，面向火腿、徒步/背包客与 DIY 爱好者，
> 开源、QRP、自包含。

作者列出的功能与硬件（原文要点）：

| 类别 | 需求 |
|---|---|
| 频段 | **0–35 MHz** |
| 显示 | 瀑布图 |
| 模式 | 收 AM / USB / LSB / CW；发 USB / LSB |
| 滤波 | 可变带通滤波器 |
| 核心 | ARM 处理器、彩屏、正交采样检波与激励、数字可控仪表放大器 |
| 频率 | 双 DDS 合成器（注：实际板用 **Si5338**，README 的"双 DDS"是更早版本的说法） |
| 人机 | 摩斯键（机身右下"Giblet"）、编码器、内置麦克风与扬声器 |
| 测量 | **AD8302 增益/相位 + 阻抗桥**（VNA / 天线分析） |
| 接口 | 双 SMA、耳机麦克风、USB、microSD、**原始 I/Q 焊盘** |
| 其他 | **GPS**、内置 LiPo 与充电、高效开关电源 |
| 动机 | "市面上没有我想要的组合：好的电台闭源、更大、更贵；开源的又没有这个便携度" |

一句话：**这是一台"背包客用的、能测天线的、自带电池和屏幕的 HF QRP SDR"**，不是通用仪器。

## 3. 冗余与砍单（每项都要能"被证伪"才保留）

| 项 | 可省 | 砍掉的代价 | 建议 |
|---|---|---|---|
| VNA / 天线分析（AD8302 + 阻抗桥 + 一只 SMA + U24 开关） | ≈ **$33（12%）** | 失去"能测天线"的卖点 | **砍**，或改成**外置选件**（预留一个 IF/接口口） |
| HMC1023 可变低通 | **$30** | 失去"可变带通"字面卖点 | **用 LC 带通组替代**（§4.4 的分波段前端），钱更少、动态范围更好；这是"功能换实现"，不是砍功能 |
| GPS | $20 | 少了时间/定位 | 保留为**选装**（贴片可选不装） |
| 1210 22µF ×11 | ~$10 | 电源纹波余量变小 | 减到 6–8 颗，或按手里的 0805 换封装（改版时） |
| GaAs DPDT ×3 | $4.9（+断供风险） | 无 | **换 CMOS/继电器**（板上 MAX4525 已证明 CMOS 可用） |

**明确保留、不要动的**：混频器、LO（Si5338）、I/Q 驱动（AD8131）、巴伦、MCU、屏、电池与充电、摩斯键、
微控制器内部的 DSP 链路（FFT/FIR）。

## 4. 关于"可扩展性"（用户的决定）

- **不做**"靠升级换频段"的内置架构：设计难度高、无法在没仪器时证伪，投入产出不成比例。
- **唯一值得留的扩展**：**外置变频器（transverter）IF 口** —— 一个 SMA + 一根 PTT 线（< $2），
  想把 2 m/70 cm 交给外置设备时直接接上。这是"留一个口"，不是"设计一套可编程前端"。
- 想直接提升性能时：**换板子比改这板便宜**（用户原话的意思），本文档同意。

## 5. 降本后的目标区间（粗算）

保留核心（HF 收发 + 瀑布 + CW/SSB + 电池/屏/摩斯键 + I/Q 输出焊盘），
砍 VNA、GPS 改选装、HMC1023 换成 LC 带通组、减 1210 电容：

```
$276.78  →  约 $190–200（−28% 左右）
```

同时解决两件事：**两颗断供件（GaAs DPDT、SBB 级放大器）** 与 **HMC1023 的 VDDBG 供电缺口**。
以上是量级估算，不是报价；每一颗都要按实际采购价重算。

## 6. 不做的清单（写死，避免下次又讨论一遍）

- 射频直接采样（成本跳档；见 §4.5）；
- 引入 RTOS / 更换 MCU 平台（§survey 架构判断）；
- 内置多波段"可升级"前端（本文 §4）；
- 让固件承担可编程滤波器组的复杂调度（固件冻结；只出"波段↔控制线"表）。
