# 替代件与局部改版提案（fork-only，不是选型决定）

日期：2026-11-02。**本文是提案，不是设计结论**：具体型号、频段余量、隔离度指标都是射频决定，
必须由有仪器的人拍板。本文没有改动任何设计文件或源码，只把"能不能换、换了要动哪里"摆清楚。

数据来源：`Hardware/PSDR.asc`（`468dc41`）的网表/封装（391 件 / 278 网 / 1132 脚）、
`PSDR2.6.1_BOM.xls`、以及公开网页资料（每个结论都标了依据强度）。

## 1. U304（RF 放大器）的封装与引脚参数

**实测（来自我们自己的板子数据，不是猜）**：

| 项 | 值 |
|---|---|
| 封装形式 | 3 焊盘、单面贴装（本板在 **B.Cu 背面**） |
| 每个焊盘 | **1.6 mm × 0.7 mm** |
| 焊盘间距 | **1.57 mm**（相邻焊盘中心） |
| 器件原点 | 板坐标 (10.160, −45.974) mm；旋转 0° |
| 网表引脚 | 1 = `RFIN`（网 `RF_AMP_IN`）、2 = `GND`、3 = `RFOUT`（网 `RF_AMP_OUT`） |
| 测试点 | TP `BIAS` 直接挂在 `RF_AMP_IN` 节点上 |

**偏置拓扑（这一条决定能不能直接换料）**：

```
RFOUT ──L19(220µH)── +5V_AMP          ← 输出侧供电（与 SBB5089Z 的"脚3=RFOUT/VCC"一致）
RFIN  ──L11(220µH)── R6(180Ω) ── +5V_AMP   ← 输入侧还有一路经 180Ω 的直流馈入
        （同网络里还有 R14=68Ω、R268=100Ω、R12=10Ω 等偏置/限流件）
```

⚠️ **未决的关键问题**：主流 SOT-89 增益块（SBB 家族、以及下面列的国产 FW2106）通常**只从输出脚供电**，
输入脚是纯 RF 输入。本板却给输入脚也馈了直流（L11+R6）。这要么说明原件的输入脚内部就是偏置节点，
要么说明这一路是为别的型号准备的。**换料前必须用原件/新件手册把这一条核清楚**——
如果新件不允许输入脚外加直流，就必须同时改偏置网络（局部改版的一部分）。

## 2. 放大器候选（全部标"待核"）

| 候选 | 关键参数（公开资料） | 与我们的约束 |
|---|---|---|
| Qorvo **SBB2089Z** | 50–850 MHz、增益 20 dB、NF 2.7 dB、SOT-89、5 V | **最低 50 MHz**——PSDR 工作在 HF，低频下限是硬门槛，需核原件在该频段的增益 |
| Qorvo **SBB5089Z** | 50 MHz–6 GHz、20 dB、NF 4.2 dB、SOT-89 | **已宣布停产**（最后购买期 2025-12-21），Qorvo 给的后续型号是 **QPA9126** |
| 国产 **通量科技 FW2106** | 50 MHz–6 GHz、21.5 dB@100 MHz、SOT-89、**与 SBB5089 pin-to-pin** | 国产化里最接近的一个；同样受"低频下限 50 MHz"与"输入侧直流"两条约束 |
| Qorvo **QPA9126** | Qorvo 对 SBB5089 的官方后续 | 封装/引脚需核 |

**结论**：有候选，但**没有一个能凭公开资料直接判"可换"**。关键未知按优先级：
①新件在 0.5–30 MHz 的增益/噪声；②输入脚能否承受本板的直流馈入；③SOT-89 焊盘（1.57 mm 间距）与新件丝印是否吻合。

**三条硬约束**（比"国产/进口"重要得多）：
1. **封装逐字相同**——改了 footprint 就不再是"能按上游 CAM 下单"的那块板；
2. 电容要核**介质类型与耐压**（X5R/X7R/C0G 的高容值项尤其要看直流偏压后的实际容量）；
3. 电阻要核**精度与温漂**（本表里 1% 与 0.1% 不能混用）。

## 4. 两颗停产 IC：现状与路线

### 4.1 `MASWSS0129`（U16/U24/U30，13 焊盘 DPDT）

- 公开资料：**GaAs 宽带 DPDT，DC–6 GHz**（同系列另有 `MASWSS0129SMB` 评估板型号）。
- 同族 `MASWSS0130TR`：**0.5–3 GHz、12-PQFN 3×3** ⇒ **频段与封装都不兼容**，不能直接换。
- 检索没有找到可核实的 pin-to-pin 替代（中英文检索都只返回同族或无关结果）。

三条路线：

| 路线 | 做法 | 代价 | 风险 |
|---|---|---|---|
| A. 原货 | 作者存量 / Rochester / 贸易商 | 无改板 | 长期不可持续；来路不明的件有假货风险 |
| B. 同族换型（局部改版） | 找 **DC–6 GHz 的 DPDT**（不同封装也行），改该区域封装与控制走线 | 改 3 处布局 + 改控制真值表 | 需重测插损/隔离/切换时间 |
| C. CMOS 模拟开关替代 | 用 2×SPDT 或 CMOS DPDT（HF 频段完全可行；板上已有 `74CBTLV3253` 做滤波选择） | 可能要加驱动/改电平 | 导通电阻、寄生电容、隔离度需重算；与射频设计强相关 |

### 4.2 `U304`（见 §1/§2）

结论相同：有候选（SBB2089Z / SBB5089Z→QPA9126 / 国产 FW2106），但**都得先解决低频下限与输入侧直流两条**。

## 5. 局部改版的范围建议（"唯一解法"落到图纸上）

只动这两块区域，**不碰其余布局**（其余部分的制造数据已与上游 CAM 对账过）：

1. **U304 周边**（约 10 × 8 mm）：换封装库（若焊盘间距不同）、按新件手册决定是否保留 L11+R6 输入侧偏置、
   必要时改 C13/C305 的隔直位置；`TP BIAS` 保留以免丢失测试点。
2. **U16/U24/U30 区域**（三处，各约 8 × 8 mm）：换开关封装、按新件真值表改 6 根控制线极性，
   并在 `signalPath()` 的引脚表里同步（**固件目前冻结 → 先出表，不改代码**）。
3. 改完必须重出三件套：**Gerber / 贴装坐标 / BOM**，并用 `tools/reproduce_kicad.py` 重新生成板/DRC/制造包与 `SHA256SUMS`、
   用 `tools/pads_asc_placement.py` 重出贴装表；本板现有的这些基线全部作废，需要新基线。

## 6. 我不能替你决定的

- 具体选哪个型号、频段留多少余量、隔离度/插损指标定多少——**射频设计决定**；
- 改版后的性能是否达标——**需要实物 + 仪器**，本机无法验证；
- 是否接受"改用 CMOS 开关"这种结构性变化——这已经从"换料"变成"改电路"，必须由你拍板。
