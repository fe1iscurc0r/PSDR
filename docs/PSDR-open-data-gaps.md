## 2. PCB 改版 / 移植问题（全部有数字）

### 2.1 2.6 → 2.6.1 实际改了什么

逐行比对两份 BOM（2026-11-03 展平成 `Hardware/BOMs/PSDR_2.6.1/PSDR2.6_BOM_flat.csv` 与
`PSDR2.6.1_BOM_flat.csv` 后实测：**2.6 有 89 个件号行、2.6.1 有 86 个**；原文写的 86/88 是
没展平、把表头与空行算进去数的）：

- **电阻值差异至少三处，不是"只有一处"**（2026-11-03 用 `tools/bom_refdes_crosscheck.py` 逐位号展开后实测）：
  `R164` 270K→240K（`541-270KHCT-ND`→`1276-4870-1-ND`）、**`R6` 100R→180R**（→`RHM180DCT-ND`）、
  **`R14` 100R→68R**；后两条本轮才看到，之前写"实质差异只有一处 R164"是**只比了合并格写法没展开位号**造成的漏看。
- 其余差异是位号写法：2.6 用合并格 `R6,14,268` / `R97,-99`，2.6.1 拆成 `R6`/`R14`/`R268` 与 `R97-99`
  （这正是 PR #18 修正的那两处）。
- ⚠️ 另有一类不是版本差异而是**数据源自相矛盾**：板文件 `Hardware/PSDR.asc` 的 `Value` 与 2.6.1 BOM
  在 **11 个位号**上不一致（清单与两种读法见 `docs/PSDR-external-findings-2026-11-03.md` §7.2/§7.3）。
  其中 `R6/R14/R164` 是板文件带着 2.6 的旧值；`R113` 是两份 BOM 都 402K、板文件 383K。

⇒ **版本迁移的风险仍很低，但"改一个电阻即可"这句作废**——按 BOM 生产是 3 个电阻值的事，
而"以哪份数据为准"是必须先定的口径（M3 可直接量，见 `docs/PSDR-bringup-checklist.md`）。
真正拉开差距的是**可机读资料**：2.6.1 有 `Hardware/PSDR.asc`（唯一可机读的完整设计源）
与完整 CAM 包，2.6 只有 Gerber 与二进制 PADS 文件（`.pcb/.sch` 不可机读）。

### 2.2 改板时绕不开的封装问题

- 全板 **1,194 个焊盘**（Top 595 / Bottom 599）、**461 个钻孔**；按层统计 Top 574 / Bottom 575 个 SMD 焊盘、45 个通孔焊盘。
- **两颗断供器件的封装不可替换**：
  - `U304` 3 焊盘（RFIN/GND/RFOUT），替代运放若引脚拓扑不同（例如需要单独的 Vd 去耦脚）就必须改板；
  - `U16/U24/U30` 13 焊盘 DPDT，替代件的控制脚数量与真值表必须一致，否则 `signalPath()` 全错。
  ⇒ 这两处**属于重新设计，不是换料**（与 §G-2 的结论一致）。
- 其余无源件换封装同样不可接受：改了 footprint 就不再是"能按上游 `468dc41` 的 CAM 下单"的那块板。

### 2.3 制造侧已知的不对称

| 项 | 现状 | 改板时要做什么 |
|---|---|---|
| 锡膏层 | CAM 包里两层是 **gerbv 2.6A 二次导出**，母片里 **0 个 G36/G37 区域**；我们的 KiCad 板不建模锡膏（默认能生成每面 574 个实心开口，是母片孔数的约 3 倍） | 钢网只能用 CAM 母片；若重新出板，需从新设计导出锡膏层并与母片对账 |
| 丝印 | CAM→我们 97.7%/97.4%，残差全是字符级（最大 1.05×1.18 mm），来自笔画字体 vs 描边字 | 改版若换字体，这个差异会放大；建议沿用同一字体族 |
| 设计规则 | 源：通用 8 mil、铺铜 12 mil、铜到板框 20 mil；EDA 工程：信号 6、线对线 4、铺铜 10 mil | 送厂前必须统一，否则厂检口径与设计口径不同（见 §C-22） |
| EDA 导入 | KiCad→EDA 与 `.epro2` 再导入无 typed 接口（`unsupported`），只能人工两步 | 见 `docs/SOP-eda-import-2.6.1.md`；改版后这套 SOP 要重跑一遍 |

### 2.4 固件移植到新板的问题

- 两棵树的引脚定义都散落在 `main.c`/`hal.c`（`signalPath()` 里 10 个引脚写死），**换板就要改业务代码**；
  建议改版时先把"模式→引脚状态"抽成表（§survey 2.7）。
- 引脚与网表的对应关系已经整理成表（§survey 2.7），可以直接拿去做新板的 pinmux 核对。
- `HMC1023`（U287）在固件里没有任何驱动——新板若保留这颗，必须先把 SPI 配置补上，否则滤波路径永远是空的。

## 3. 结论

1. **资料侧的大头已经清掉**（2026-11-03，见 `docs/PSDR-external-findings-2026-11-03.md`）：
   HMC1023 寄存器表、AD8302 公式与 +10 dBm 绝对上限、Si5338 Rev 1.6 的版本差与 MultiSynth 约束、
   CB3Q/CBTLV 真值表与 Ron、EP52 无 fmin 规格、STM32 勘误 ES0290 §2.2.1（ADC 触发丢失）都已到手或已结案。
   **还缺的只有原厂 PDF**：MASWSS0129（MACOM 撤档）、SXB-2089Z（Qorvo 撤档）、FAN4174（onsemi 拦）、
   RXM-GPS（TE 只给查看器）、SPU0410、W3062A —— 在拿到之前相关结论按 `镜像` 级用，不出门。
2. **PCB 改版本身不难，但"2.6→2.6.1 只差 R164"这句已作废**：至少 R6、R14 也是同批改动（§2.1），
   另有 **11 个位号板文件与 BOM 直接冲突**（findings §7.3），必须先用 M3 实测定口径。
   真正的硬约束仍是**两颗断供器件的封装不可替换**；任何替代方案都按"重新设计"评估。
3. 制造侧三个口径（锡膏母片、丝印字体、设计规则）在改版时必须重新对账，不能沿用本板的数值。
