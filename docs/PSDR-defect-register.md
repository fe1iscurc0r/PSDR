## 可立即执行的修法（不需要板子、不需要改设计文件）

### 1. `VDDBG` 飞线（D-02）

* 目标：给 `U287.28` 供 **5 V**（与 `LPF_5V` 同电位）。
* 落点（网表实测）：`LPF_5V` 在 `U287.22`/`U287.16`/`U287.2`/`U287.4`/`U287.21`/`U287.23` 都有；
  最方便的是 **`U287.22`（VDDCAL）到 `U287.28`（VDDBG）**——两脚相邻（22 与 28 不同边，实际仍要飞线），
  或从 **`C292` 的热端**接 `LPF_5V`（`C292` 另一端是 GND）。
* 线径/长度：5 V 偏置电流小，普通细线即可；飞线后**用万用表确认 pin 28 对 GND 是 5 V 而不是 0 V**。
* 这条飞线**不改任何设计文件**，只在台架上做；rev-B 才把它变成铜。

### 2. 上电先量的四件（已写进检查表）

1. `+3V3_CPU` 是 **2.898 还是 3.012 V**（对应 R113 实测值，D-11/D-12）；
2. `+5V_BOOST` 是否 ≈ **4.94 V**（ADP1613 分压）；
3. `VDDBG` 脚（飞线后）是否 **≈5 V**（D-02）；
4. `FILTER_CAL`（`C283` 靠 Si5338 那一侧）**有没有 20–80 MHz 时钟**（D-10）。

### 3. 板厚/工艺（D-16）

下单时：**4 层 / FR4 / 1 oz / 板厚 1.0 mm（或按 0.9 mm 询问）/ 沉金**；
DFM 预检用**原始 Gerber 包**（`Hardware/Gerbers/PSDR261 Main Board/`），不要先传重建的 KiCad 版。
