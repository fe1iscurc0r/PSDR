# 无射频板桥接直通焊接表（U16 / U24 / U30，2026-11-23）

适用：嘉立创免费打样的 2.6.1 板，**不贴 U304 / U16 / U24 / U30**（停产 RF 件）。
不桥接则天线口到混频器是断的，**收、发都没有通路**（`PSDR-defect-register.md` D-24）。
本表只给"焊哪两脚"，**走线/飞线/补焊由用户执行**（项目边界：我不画线）。

## 1. 通路怎么来的（网表逐脚，物理锚点）

主 RF 串联通路（`dist/netlist/PSDR_2.6.1_netlist.json` 实测）：

```
ANT/VNA-IN.1 ─C303─► U16.10 ┈┈ U16.6 ─C21─► U24.10 ┈┈ U24.6 ─C27─► U30.10 ┈┈ U30.4 ─C35─► L39.6 ─► 混频器
                    (旁路放大)                  (旁路阻抗电桥)              (选 ANT，弃 VNA-REF)
```

每片是 MASWSS0129 13 焊盘，**RF 脚只有 4/6/10/12**（其余 7 脚 GND、3/7 是 V1/V2 控制）。
"进脚 / 出脚"由各自所连的网络定死，**与 DPDT 内部公共/掷的接法无关**——把进脚和出脚直接短接，
RF 就连续，等价于该开关处于"直通"档。

| 片 | 进脚（来源） | 出脚（去向） | 旁路/弃用的脚 |
|---|---|---|---|
| U16 | **10**（← C303 ← ANT） | **6**（→ C21 → U24） | 12=放大输入(C13)、4=放大输出(C305)，U304 不贴则空着 |
| U24 | **10**（← C21 ← U16） | **6**（→ C27 → U30） | 12=IMP_BRIDGE_IN(C20)、4=IMP_BRIDGE_OUT(C26)，电桥不用则空着 |
| U30 | **10**（← C27 ← U24） | **4**（→ C35 → L39 → 混频器） | 12=RF_REF(C306，VNA 参考)、6=空掷位（无网络） |

## 2. 桥接表（照这个焊）

| 片 | 短接 | 跳线长度 | 备注 |
|---|---|---|---|
| **U16** | pin **10 ↔ pin 6** | 跨封装两对角焊盘 | 放大通路 12/4 留空（U304 本来就不贴） |
| **U24** | pin **10 ↔ pin 6** | 同上 | 阻抗电桥 12/4 留空（VNA 才用） |
| **U30** | pin **10 ↔ pin 4** | 同上 | 12(VNA-REF)/6(空掷) 留空 |

- 三片都在 **Top 面**、x=16.002 mm 一列（U16 y=44.958、U24 y=36.830、U30 y=28.702），相邻好飞。
- 焊锡桥要**短、粗、接地就近**：RF 脚裸焊盘之间直接堆锡即可；别绕远线，否则引入串接电感。
- 控制脚 3/7（V1/V2）和 GND 脚**不用动**；固件照样写 AMP/IMP/TX_RF 六根线，但已无电气作用。

## 3. 桥接后能/不能做什么

- ✅ **RX（LSB/USB/AM/FM）和 TX 测试音**恢复通路：信号直接 ANT↔混频器，不经放大、不经电桥。
- ✅ 验 **VDDBG 蚀刻修复**：桥接后走 HMC1023（控制台 `l1`/`l2`）用信号源看通带抬升（判据是过信号，不是 SPI 读回）。
- ❌ **VNA/天线分析**不可用（U30 被钉在 ANT、U24 电桥被旁路）。要用 VNA 时拆掉 U24/U30 的桥、贴回件或另接。
- ❌ **发射大功率档不可用**（U304 不贴）：TX 只有经 HMC1023 的 ~0 dBm 档；任何发射先接衰减器/假负载+低通，**别接天线**（README/`#16` 一致）。
- ⚠️ 桥接 = 永久"直通"，与 `signalPath()` 档位无关；这是**台架临时态**，不是 rev-B 方案（rev-B 用 ZDH5438/继电器替换三片，见 `PSDR-revB-workorder.md` §8）。

## 4. 复算（重跑即得同一张表）

```bash
python - <<'PY'
import json,io
d=json.load(io.open('dist/netlist/PSDR_2.6.1_netlist.json',encoding='utf-8'))
nets=d['nets']
def netof(ref,pin):
    return [n for n,mem in nets.items() for m in mem if m['refdes']==ref and m['pin']==str(pin)]
for s in ('U16','U24','U30'):
    rf=[p for p in (4,6,10,12) if netof(s,p)]
    print(s,'RF pins',[ (p,netof(s,p)) for p in rf])
PY
```

出处：脚-网络映射 = 网表实测；三片 Top 一列 = `PSDR-dossier-DPDT-switches.md` §2；
U30 pin6 空掷 = 同档 §1；串联关系与 C303/C21/C27/C35/C306 耦合 = 网表逐脚。
