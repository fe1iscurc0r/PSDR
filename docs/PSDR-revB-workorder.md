## 2. 影响圈：数据说"局部"在射频路径上基本不成立

`tools/revB_zone_closure.py`（本轮新增，重跑：`python tools/revB_zone_closure.py`）
按网络传播，**参考网不传播**（`GND` 261 脚、`+3V3` 58、`+3V3_CPU` 50、`HALF_VCC` 23 等一律挡掉并列在
`dist/revB/zones_summary.md`，排除是可查的不是假设）。结果：

| 区 | 种子 | 区内件数 | 一跳邻居（含种子） | 二跳 | 一跳包围盒（mm，贴装表原点＝板框左下角） |
|---|---|---|---|---|---|
| U304 增益级 | `U304` | 9 | **6**：`U304 BIAS C13 C305 L11 L19` | 3 | x 7.9–16.0, y 42.2–50.5（约 8×8 mm） |
| 三片 DPDT | `U16/U24/U30` | 102 | **13**：三片 + `C13 C20 C21 C26 C27 C303 C305 C306 C35 U121` | 89 | 铺满全板（x 0–96.2, y 2.5–61.0） |
| HMC1023 | `U287` | 99 | **14**：`U287 C283 C292 C293 C294 R285 R286 R296 R297 U121 U15 U211 U298` | 86 | 同上 |
| 天线口（2026-11-04 加） | `ANT/VNA-IN`、`REF`、`DUT`、`VNA-OUT` | 19 | **12**：四个端子 + `C303 C306 C309 C322 R28 R29 R308 R321` | 7 | x 4.2–16.0, y 25.1–55.0 |

（天线口那一行由 `python tools/revB_zone_closure.py --zone "antenna_ports:ANT/VNA-IN,REF,DUT,VNA-OUT"` 生成；
不加 `--zone` 时只跑内置三区。）

**读得**：**四区并集 129** 件，板上一共 **391** 件 ⇒ **影响圈外必须逐件不变的是 262 件**。
（K-17 当时只算三区是 124 / 267；加上天线口后 129 / 262，判据用**新的这对数**。）

**算得/结论（这条是本工作单最重要的一句）**：**只有 U304 区是真·局部（一跳 6 件、8×8 mm）**；
DPDT 与 HMC1023 二跳就铺满全板——因为射频路径每一跳都是下一级的输入，
"局部改 RF"在网表意义上不存在。⇒ rev-B 若要"只做局部"，**范围只能定义成**：

* (a) **U304 子图**（含 `BIAS`/`L11`/`L19`/`C13`/`C305`）——真局部；
* (b) **三片 DPDT 各自的 1 跳邻居**（共 13 件）——只在换封装/改掷位时动；
* (c) **HMC1023 的 1 跳邻居**（14 件，含 `U211/U298` 与 `U15`）——只在决定是否保留这颗时动；
* (d) **天线口子图**（12 件，含 `R28/R29/R308/R321` 与四个端子）——只在动 VNA/天线插座时动；
* 其余 **262 件 = 硬约束**：任何改动导致这 262 件的贴装/网络变化，就不叫 rev-B，叫重设计。

验收命令（**签名按各工具现有 argparse 写实**，可判定，不许用综合分代替）：

```bash
# 1) 重出影响圈（本轮新增，不需要 EDA）
python tools/revB_zone_closure.py

# 2) 改版后重出贴装表（输入是新版 .asc 或新版 KiCad 导出的等价坐标表）
python tools/pads_asc_placement.py <新板 ASCII> --out dist/fab/revB_placement.csv

# 3) 网络对拍：三赛区外的网络必须逐集合一致
python tools/kicad_netlist_compare.py --pads Hardware/PSDR.asc --kicad dist/kicad/<revB>.kicad_pcb

# 4) 几何对拍（需要 kicad-cli 先画出 Edge.Cuts 与钻孔）
python tools/kicad_roundtrip_check.py --edge-export <Edge_Cuts.gbr> --drill-export <drill> --tol-mm 0.01

# 5) 一条命令重建参考板 + DRC + 制造包，并自检
python tools/reproduce_kicad.py --check
```

第 2/4 步在 267 件"逐件不变"上的判据：**坐标差＝0、面别与角度差＝0、位号集合差＝空**；
任一不为零即说明改到了局部之外，本工作单 §2(a)(b)(c) 的范围定义失效，须停下重开范围。
