# 开关映射：滤波 mux 与 VNA 路径（F-3 / F-4 的前置分析）

日期：2026-11-04。**结论先说：F-3 的 mux 通道图能从网表推出来，但"选择码 → 通道"的顺序还差一次实测；
F-4 的 VNA 继电器组合差两次实测（DPDT 的物理引脚↔端口、mux 真值表）。**
按本仓规则，**没有把猜出来的值写进固件**——`signal_path_table.h` 里 5/6 两态保持"不写"。

## 1. 三片 DPDT 的端口（网表逐条追出，读得）

| 开关 | RF 脚 → 远端 | 说明 |
|---|---|---|
| `U16` | 12 → `C13` → `RF_AMP_IN`；10 → `C303` → `ANT/VNA-IN`；4 → `C305` → `RF_AMP_OUT`；6 → `C21` → `U24.10` | 天线 / 功放输入 / 功放输出 / 桥路 |
| `U24` | 12 → `C20` → `IMP_BRIDGE_IN`；4 → `C26` → `IMP_BRIDGE_OUT`；6 → `C27` → `U30.10`；10 → `C21` → `U16.6` | 阻抗桥进/出 + 两处级联 |
| `U30` | 12 → `C306` → `RF_REF`（= `VNA-OUT` 同网）；10 → `C27` → `U24.6`；4 → `C35` → **`L39`（巴伦，去混频）**；6 → **无网络**（ANT2 空掷位） | VNA 输出 / 桥路 / 混频 / 空 |

DPDT 真值表（**镜像级**，MASWSS0129 Rev V6；原文两态导通）：

| VC1 | VC2 | ANT1-Rx | ANT1-Tx | ANT2-Tx | ANT2-Rx |
|---|---|---|---|---|---|
| 1 | 0 | On | Off | On | Off |
| 0 | 1 | Off | On | Off | On |
| 1 | 1 / 0 | 0 | Off | Off | Off | Off |

⇒ 它是**两个 ANT 口 × {Rx,Tx} 的交叉开关**：每个状态同时接通两条路径。
**缺的那一半**：13 个焊盘里哪四个是 ANT1/ANT2/Rx/Tx、哪个控制态对应哪一列——镜像文本没给物理引脚图。

## 2. 滤波 mux（`U211`/`U298`，74CB3Q/CBTLV3253）的通道图（网表，读得）

每片是双 4:1：脚 3/4/5/6 = 1B1..1B4，脚 13/12/11/10 = 2B1..2B4，脚 7/9 = 两个公共端（经电容出去），
脚 14 = S0、脚 2 = S1（与网表 `FILTER_S0→14`、`FILTER_S1→2` 一致）。

| 通道 | `U211`（IF 侧） | `U298`（RF 侧） |
|---|---|---|
| B1 | `FILTER_IN_N`（1B1）/ `FILTER_IN_P`（2B1） | `FILTER_OUT_P`（1B1）/ `FILTER_OUT_N`（2B1） |
| B2 | `FILTER_OUT_N` / `FILTER_OUT_P` | `FILTER_IN_P` / `FILTER_IN_N` |
| B3 | 交叉到 `U298`（`U211.5↔U298.11`、`U211.11↔U298.5`） | 交叉到 `U211` |
| B4 | `E_FILT_IF_N` / `E_FILT_IF_P` | `E_FILT_RF_N` / `E_FILT_RF_P` |

公共端：`U211.7/9` 经 `C209/C210` 去 `FILTER_IF_N/P`；`U298.7/9` 经 `C40/C36` 去 `FILTER_RF_?`。

⇒ 这片网络的作用是**四选一**：把信号送进 HMC1023（B1）、从 HMC1023 取回（B2）、**直通交叉（B3，即旁路）**、
接到外接滤波插槽（B4）。

**缺的那一半**：`S0/S1` 两个比特到 B1..B4 的**编码顺序**（标准 3253 是 `S1S0`: 00→B1、01→B2、10→B3、11→B4，
但必须按板上实物手册确认）。现有固件写 `(S0,S1)=(1,0)`，作者注释 "Filter Muxes set to bypass"——
若按标准顺序，"S0=1,S1=0" 正好落在 B3（交叉=旁路），与注释自洽；这是**推断，不是读得**。

## 3. VNA 两态需要什么（F-4）

`vna_reflected` 的物理含义应是：把 `U24` 切到"桥插入"、`U30` 把发射源送到 `RF_REF`（`VNA-OUT`），
`U314` 比较 `RF_REF`（经 `C322`）与 `RF_ANT`（经 `C309`）两臂。`vna_through` 则是桥旁路、直通。

要写这两个态的 12 根线，至少要知道：

1. **U24 的"桥插入"是哪一控制态**（VC1/VC2 = 10 还是 01）——取决于 U24 的 ANT1/ANT2/Rx/Tx 物理脚位；
2. **U30 的"发到 VNA-OUT"是哪一控制态**（它的 pin 6 还是空的，更增加不确定性）；
3. **mux 的 B1..B4 ↔ S0/S1 编码**（决定 `vna_*` 时 `FILTER_S0/S1` 该写什么）；
4. `TRX_SWITCH`/`DAC_MUX` 在 VNA 态的目标（大概率 RX + speaker，但要与上面三条一起定）。

## 4. 需要测的量（全部 10 分钟级，万用表即可）

| # | 测点 | 判定 |
|---|---|---|
| M1 | `U24.3`/`U24.7`（`IMP_BRIDGE_SWITCH_A/B`）分别写 1/0 与 0/1，量 `C20`/`C26` 两端对 `IMP_BRIDGE_IN/OUT` 的通断 | 得到 U24 的两态→桥插入/旁路 |
| M2 | `U30.3`/`U30.7` 同上，量 `U30.12`（去 `RF_REF`）与 `U30.4`（去巴伦）哪个通 | 得到 U30 的两态→VNA-OUT/混频 |
| M3 | `U16.3`/`U16.7` 同上，量天线口→`RF_AMP_IN`/`RF_AMP_OUT` | 顺带校正 #16 的旁路语义 |
| M4 | `U211/U298` 的 `S0/S1` 写四种组合，量 `FILTER_IN/OUT` 与 `E_FILT` 的通断 | 得到 B1..B4 ↔ 编码 |

这四条一有结果，F-3/F-4 的表格值就是"读得"而不是"猜"；**在那之前固件保持现状**。
