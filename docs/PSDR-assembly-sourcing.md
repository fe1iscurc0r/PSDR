# 贴装与选材：哪些必须机贴、哪些能手贴、哪些买不到（2026-11-04）

产物：`Hardware/BOMs/PSDR_2.6.1/assembly_class.csv`（391 行，逐件带 `cls` 与 `package_note`）。
分类**只按封装**，不按价格；`reflow` = 需要回流/热风且手贴风险高，`air` = 热风/拖焊可做，
`hand` = 电烙铁可做，`mechanical` = 测试点/安装孔/排针之类不算件。

## 1. 数量

| 类 | 件数 | 说明 |
|---|---|---|
| `hand` | **290** | 绝大多数是 0603/0805/1206/1210 阻容与电感、LED、SMA、按键 |
| `mechanical` | 58 | 33 个 `PAD_1MM` 测试点 + 6 个基准点 + 安装孔 + 排针 |
| `air` | 25 | MSOP/SOIC/SOT23/uMAX 类（U15/U85/U114/U189/U253/U260/U279/U280/U304 等） |
| `reflow` | **18** | 见下 |

## 4. 三种打法与代价

| 方案 | 做法 | 代价 | 适用 |
|---|---|---|---|
| A 混合 | 嘉立创经济型 SMT 只贴 §2 的 18 件，其余手贴 | 一次贴片费 + 自购料；0603 手贴量大（290 件）但可行 | 推荐：先验电源/MCU |
| B 全手贴 | 全部热风+烙铁 | 0.5 mm LQFP/QFN 需要练习；废板风险高 | 不推荐给第一次 |
| C 只打板不贴 | 只做裸板 + 自己贴少量关键件 | 最便宜，但 5 片里能救活几片看手艺 | 只想验证 DFM/焊接时 |

## 5. 与"配额"的关系

见 `docs/PSDR-fab-spec.md` §6：学生每月两次免费板、≤10×10 cm、OSP/沉金。**在 U304/MASWSS 的料况与
11 个值/两条轨没实测之前，打样只会得到"焊着玩"的 5 片板**——这张表就是"为什么先不打"的依据。

### 6.2 不是"一次买 $149"：分档采购（2026-11-04）

诚实拆开：**$149 是"按 2016 DigiKey 单件价买齐一块收音机"的数**，不是最低门槛。按"什么时候真的需要"分档：

| 档 | 买什么 | 2016 价（qty 加权） | 能验什么 |
|---|---|---|---|
| **P 电源**（最小物理第一步） | `U114`(AP3417C $0.41) `U161`(MCP73871 $1.79) `U85`(ADP1613 $2.07) `U172`(MCP1802 $0.53) + 5 颗 MOSFET + L84/L105/L109/L141 + USB + 22 µF/10 µF + 阻容 | **约 $20** | 两条轨（`+3V3_CPU` 2.898/3.012 V、`+5V_BOOST` 4.94 V）与焊接 |
| **M MCU+时钟** | `U121`($16.75) + `U241`($14.79) + 晶振($1.26) + BOOT/RST 按键 + 编程排针（+ P 档全部） | **约 $55–60** | 固件能不能跑过 `main()`（`Si5338` 是开机阻塞点） |
| **A 音频/SD** | TPA0253/SSM2167/喇叭/microSD | +$10–15 | 音频与存储 |
| **R 射频**（买不到/未定） | HMC1023 $30.32、AD8302 $24.86、GPS $20.38、SMA $14.30、混频管、巴伦、DPDT | 约 $100+ | 等 G1/G3 有结论再说 |

**省钱杠杆（按效果排序）**：
1. **通用件换渠道**：22 µF/1210（$18.15）与 SMA（$14.30）是两条最冤枉的 DigiKey 单件价，LCSC/嘉立创同类通常低一个量级；
2. **阻容买套件**：234 个 0603/0805 阻容按套件买，比逐条 BOM 便宜；
3. **只买 1 套料**：免费给的是 5 片**板**，不是 5 套料；
4. **P 档先做**：$20 就能验证"板子焊得动、轨压对不对"，不碰 STM32/Si5338 这两颗贵的；
5. **射频档先不买**：等 U304 / DPDT 的替代方案定了再花那 $100。

对照：全板（含射频/音频/GPS/SMA）2016 价 **$272.54**；最小可验板 **$149.32**；"先买 P 档"**约 $20**。
