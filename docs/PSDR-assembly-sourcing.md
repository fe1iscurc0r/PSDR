# 贴装与选材：哪些必须机贴、哪些能手贴、哪些买不到（2026-11-04）

产物：`Hardware/BOMs/PSDR_2.6.1/assembly_class.csv`（391 行，逐件带 `cls` 与 `package_note`）。
分类**只按封装**，不按价格；`reflow` = 需要回流/热风且手贴风险高，`air` = 热风/拖焊可做，
`hand` = 电烙铁可做，`mechanical` = 测试点/安装孔/排针之类不算件。

## 1. 数量

| 类 | 件数 | 说明 |
|---|---|---|
| `hand` | **290** | 绝大多数是 0603/0805/1206/1210 阻容与电感、LED、SMA、按键 |
| `mechanical` | 58 | 33 个 `PAD_1MM` 测试点 + 6 个基准点 + 安装孔 + 排针 |
| `air` | 25 | MSOP/SOIC/SOT23/uMAX 类（U15/U85/U114/U189/U253/U260/U279/U280/U304 等） |
| `reflow` | **18** | 见下 |

## 3. 买不到 / 无原厂资料（决定"能不能全贴"的硬约束）

| 位号 | 器件 | 状态 |
|---|---|---|
| `U304` | **SXB-2089Z**（封装名是化石 `HMC482ST`） | **买不到**：原厂页检索不到 + 我方出口 429；三条独立来源指向 SXB，但无原厂 PDF |
| `U16`/`U24`/`U30` | **MASWSS0129TR** | **买不到**：原厂 CDN 本件 404（兄弟件 200），2021 年 Jeff 已在 win-source/Richardson 找到过渠道，现况未核 |
| `U32` | SPU0410HR5H-PB | 可买（DigiKey `423-1138-1-ND`），但**无原厂手册** |
| `GPS_ANTENNA` | W3062A | 可买（`553-2579-1-ND`），但**无原厂手册**（Pulse→YAGEO 断链） |

⇒ **"全部贴完"在当前料况下不可能**：两只射频件缺货。可行的最小板是"除了 U304/U16/U24/U30 之外的都贴"，
射频链留空——这块板只能验电源、时钟、MCU 与外设，不能验射频。**这正是"先别打样"的理由之一。**

## 4. 三种打法与代价

| 方案 | 做法 | 代价 | 适用 |
|---|---|---|---|
| A 混合 | 嘉立创经济型 SMT 只贴 §2 的 18 件，其余手贴 | 一次贴片费 + 自购料；0603 手贴量大（290 件）但可行 | 推荐：先验电源/MCU |
| B 全手贴 | 全部热风+烙铁 | 0.5 mm LQFP/QFN 需要练习；废板风险高 | 不推荐给第一次 |
| C 只打板不贴 | 只做裸板 + 自己贴少量关键件 | 最便宜，但 5 片里能救活几片看手艺 | 只想验证 DFM/焊接时 |

## 5. 与"配额"的关系

见 `docs/PSDR-fab-spec.md` §6：学生每月两次免费板、≤10×10 cm、OSP/沉金。**在 U304/MASWSS 的料况与
11 个值/两条轨没实测之前，打样只会得到"焊着玩"的 5 片板**——这张表就是"为什么先不打"的依据。
