## 改动 A：`VDDBG` 供电（唯一的功能性改板）

**现状**：`U287.28`（VDDBG）与 `C292.1` 在一个私有网 `$$$15137` 上，该网没有任何电源馈入。

### A1 先合并网络
把 `$$$15137` 这个网**改名/合并到 `LPF_5V`**（该网只有 `U287.28` 与 `C292.1` 两个焊盘）。
在 EasyEDA 里：选中该网 → 重命名 `LPF_5V`；或在网络管理器里把两个焊盘指到 `LPF_5V`。
> 不改名直接拉线，DRC 会报"不同网络短路"。

### A2 加一段铜（B.Cu，宽 0.2032 mm = 8 mil）
| 端点 | 坐标（mm） | 是什么 |
|---|---|---|
| 起点 | **(34.29, -10.541)** | `C292` pad 1（VDDBG 侧，非地） |
| 终点 | **(37.084, -13.843)** | `C291` pad 1（`LPF_5V` 侧，非地） |

直线 4.32 mm。**障碍（实测）**：这条直线附近有 3 段 B.Cu 线在 0.167–0.177 mm 处、1 段 F.Cu 线在 0.037 mm 处
⇒ **不要直连**。两种走法任选：
* 同层绕行：从起点先向 +X 偏 0.4–0.6 mm，再斜向终点，保持与其它网 ≥0.15 mm；
* 换层：起点附近打一个 0.8128/0.3556 mm 过孔 → F.Cu 走 → 终点附近再打一个过孔回 B.Cu。
（F.Cu 那条线离直线只有 0.037 mm，走 F.Cu 时要避开它。）

### A3 验收
* DRC：新增线与任何网的间距 **≥0.15 mm**（最好 ≥0.2 mm）；
* 连通性：`U287.28` — `C292.1` — `LPF_5V` 同网且无断点；
* 重新铺铜后仍是 **12/12** 非空。

## 改完后必须做的四件事

1. **重新铺铜**（12 个区），确认 12/12 非空；
2. **跑 DRC**：目标 `clearance` 无 <0.15 mm；其它类别维持原样（795 条的分类不变）；
3. **重出 Gerber/钻孔**，与原始包做一次层覆盖对账；
4. 更新 `dist/kicad/SHA256SUMS`（旧清单只对应改前版本），并把改后文件另存一个版本号。

## 不要动的东西

| 项 | 原因 |
|---|---|
| 板厚 | 下单参数（1.0 mm），不是版图 |
| 丝印位号 | 只影响看板；厂方会裁。要改是另一件事 |
| `U30.6` 引出测试点 | 可选，与首样无关 |
| 器件位置/封装 | 一旦挪动，影响圈外的 262 件判据失效 |

## 已由我这边执行的改动（2026-11-04）

### D. `EARPHONE` 1 号脚（GND）被板框圆角切角

* **实测几何**：板左下角圆弧圆心 **(4.4832, -4.4579)**、半径 **4.4581 mm**；
  1 号焊盘原中心 **(1.0, -2.825)**、尺寸 **1.25 × 1.2 mm**，其外角到圆心 **4.676 mm > R** ⇒
  **焊盘外角伸出板外 0.218 mm**（这就是 DRC 里 `copper_edge_clearance` 实际 0.0000 那条）。
* **已改**（`dist/kicad/PSDR_2.6.1_pcb_spike_full.kicad_pcb`，仅这一个焊盘）：

```diff
- (pad "1" smd roundrect
-   (at 1.0000 4.1750 -270.0000)
-   (size 1.2500 1.2000)
+ (pad "1" smd roundrect
+   (at 1.3000 4.1750 -270.0000)
+   (size 1.1000 1.1000)
```

* **改后几何**：中心 (1.3, -2.825)、1.1×1.1，外角到圆心 **4.3245 mm** ⇒
  距圆弧 **0.134 mm**（不再被切）；到下方缺口线（y=-3.7846）**0.41 mm**。
* **性质**：这是**对连接器 land pattern 的偏移**（焊盘向板内 0.3 mm、缩小 0.15 mm），
  不是只改板框。插座引脚仍落在焊盘范围内（1.1 mm 焊盘 vs 常见 0.5 mm 引脚），但**未对照 SJ-42617 原厂推荐 land pattern 核过**——
  若你有该插座图纸，请核一下"1 脚焊盘中心到外壳基准"的推荐值；偏差超过 0.3 mm 就要改回并改用"改板框"方案。
* **未做**：DRC 未重跑（本机没有 kicad-cli）；`SHA256SUMS` 未更新——这份板现在**带手工改动**，
  `tools/reproduce_kicad.py` 会用 `.asc` 重新生成并**覆盖**它，请把改后文件另存为 `..._revB.kicad_pcb` 再继续。
